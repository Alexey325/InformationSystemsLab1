добавил регистрацию и вход пользователя через spring security на сессиях

- регистрация: пароль хранится только в виде bcrypt-хэша, новый пользователь всегда получает роль USER, занятый логин -> 409
- вход: проверка логина/пароля через spring security, после успеха пользователь сохраняется в HTTP-сессии (cookie JSESSIONID), id сессии меняется при входе
- неверный логин или пароль -> 401 с одинаковым ответом, хэш пароля наружу не отдаётся
